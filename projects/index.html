Things I've built and still maintain. Smaller experiments, forks and older examples live on GitHub.

[ current ]

  1. 01

    plantuml-mcp-server

    An MCP server for PlantUML. Started in my own repository; the source now lives under the Infobip organization, and the npm package is still called plantuml-mcp-server.

  2. 02

    pi-mcpc-status

    Session status and controls for mcpc, rendered inside the Pi terminal UI. Small on purpose: it should stay out of the way.

  3. 03

    hep_mjerenje_scrapper

    Scraper and dashboard for Croatian HEP electricity meter data. Imports consumption and production into SQLite and charts it, mostly to keep an eye on the solar panels.

  4. 04

    Backyard Deep Sky

    A static gallery of deep-sky photographs, generated from its own repository and served as a separate GitHub Pages site.
