Colophon

Hand-written HTML and one stylesheet. No framework, no build step, no JavaScript, no external fonts, no CDN, no analytics, no cookies.

Text is set in the system sans-serif; labels, numbers and the footer use the system monospace. The palette is borrowed from Backyard Deep Sky: #0a0c11, #e9edf5, #8b93a7, #7fb0ff.
